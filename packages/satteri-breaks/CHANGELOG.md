# satteri-breaks

## 0.2.0

### Minor Changes

- 3433973: Require Sätteri 0.10. The `satteri` peer range is now `^0.10.0`; Sätteri 0.9 is no longer supported.

## 0.1.0

### Minor Changes

- 174981e: Add `satteri-breaks`, a port of `remark-breaks` that turns single newlines into `<br>`. Fenced and
  inline code are untouched, and CRLF line endings are handled.
