# {frontmatter.title}

This page is MDX. Its frontmatter is exposed as an export by
`satteri-mdx-frontmatter`, so the heading above reads `frontmatter.title` and
renders **{frontmatter.title}**.

Without that plugin, `frontmatter` is an undefined free variable and the page
throws at render rather than at build, which is the worst place to find out.
